# Questionário pré-anestésico — APA Digital

Página estática que o paciente abre pelo link enviado pelo anestesista no app APA Digital.

- Não guarda respostas: elas são cifradas no navegador do paciente (AES-GCM) e voltam ao anestesista pelo WhatsApp, dentro do próprio link.
- Só o iPhone que enviou o questionário tem a chave para ler as respostas.
- Cópia da pasta `questionario/` do repositório do app.
